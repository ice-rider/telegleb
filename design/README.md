# Дизайн интерфейса

Макеты экранов Telegleb. Не подключены к сборке — это визуальный референс,
по которому предстоит переписывать вёрстку клиента.

## Как посмотреть

Откройте `telegleb-interface.html` в браузере (двойной клик или
`xdg-open design/telegleb-interface.html`). Это канвас с шестью артбордами:
панорамирование, зум, выделение элементов и экспорт в PNG/PDF. Правки в нём
никуда не сохраняются — канвас не опубликован, это локальный файл.

Исходники артбордов лежат рядом как обычный HTML (`*.dc.html`) — их можно
читать и править в редакторе; `canvas.json` задаёт раскладку и страницы.

## Что нарисовано

**Страница «Приложение»** — ведущее направление A, «тёмный неон»:

| Артборд | Экран |
|---|---|
| `Main.dc.html` | Список чатов с папками и переписка |
| `Forum.dc.html` | Темы супергруппы |
| `Priority.dc.html` | Важные чаты и двухфазная загрузка |
| `Auth.dc.html` | Три шага входа |

**Страница «Направления»** — альтернативы для сравнения:

| Артборд | Направление |
|---|---|
| `DirectionB.dc.html` | Печатный брутализм: Archivo Black + IBM Plex Mono, жёсткие рамки, смещённые тени |
| `DirectionC.dc.html` | Мягкий дневной свет: Instrument Serif + Karla, тёплая бумага, терракотовый акцент |

## Решения, заложенные в макеты

- **Иконки — inline SVG, а не эмодзи.** Сейчас в клиенте закреплённые чаты,
  папки и типы чатов помечены эмодзи (📌 🔕 👥 📢): они по-разному выглядят в
  разных системах и не поддаются перекраске.
- **Раскладка по папкам приходит с сервера** вместе с чатами — вкладки и
  список появляются одновременно, см. [`../docs/API.md`](../docs/API.md) §3.4.
- **Форум открывается списком тем**, а не сообщениями: плоской истории у него нет.
- **Важные чаты** (этап 1.5 в [`../docs/ROADMAP.md`](../docs/ROADMAP.md)) —
  звезда в карточке, отдельная вкладка и индикатор «6 / 214», пока догружается
  остальное.
- Моноширинный шрифт для времени и счётчиков: цифры не прыгают при обновлении.

Содержимое чатов в макетах вымышленное.

## Пересборка канваса

`telegleb-interface.html` собран из `*.dc.html` и `canvas.json` инструментом
Claude Design и хранится готовым, потому что сборщик живёт вне репозитория.
Файл весит 2,5 МБ — в нём редактор канваса. Если правите `*.dc.html`, канвас
нужно пересобрать тем же инструментом, иначе он останется со старым содержимым.
